# PetCare Eureka Server

## Project Description
Service-discovery server for the PetCare microservices system. Backend services register with Eureka and the API Gateway uses service names for routing.

## Technology Stack
- Java 21
- Spring Boot
- Spring Cloud Netflix Eureka Server
- Maven
- Git / GitHub

## Setup / Getting Started
1. Start Config Server on port `8888`.
2. Start Eureka Server.
3. Start the remaining registered services.

Eureka Dashboard:
`http://localhost:8761`
